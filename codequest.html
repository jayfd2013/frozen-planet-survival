📚 JavaScript Reference

Real JavaScript — the same syntax works in any project, website, or app.

Variables — store a value

let score = 0;
let name = "Kaiya";
const PI = 3.14;   // can't change
score = score + 10;   // update it
score++;              // add 1 (shortcut)

Math & comparisons

a + b   a - b   a * b   a / b
a % b   // remainder
a > b   a < b   a >= b   a <= b
a === b // equal?   a !== b // not equal?
a && b  // and    a || b // or   !a // not

If / else — decisions

if (score >= 10) {
  say("You win!");
} else {
  say("Keep going");
}

Loops — repeat

for (let i = 0; i < 5; i++) {
  moveForward();
}
while (canMove()) {
  moveForward();
}

Arrays — lists of values

let items = [3, 1, 4];
items[0];          // 3 (first)
items.length;      // 3 (how many)
for (const n of items) {
  say(n);
}

Functions — name & reuse

function advance() {
  moveForward();
  collect();
}
advance();   // run it

Robot commands (this game)

moveForward()  // step ahead
turnLeft()  turnRight()
collect()      // grab a gem
read()         // number on signpost
say(value)     // print to console

Sensors — true / false

canMove()   // path ahead open?
isAtGoal()  // on the flag?
isOnGem()   // gem here?
// use inside if(...) or while(...)
