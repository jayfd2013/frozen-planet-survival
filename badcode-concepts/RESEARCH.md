# Web research notes (2026-10-03)

## What makes short explainers work
- Nicky Case (Parable of the Polygons, Evolution of Trust): open with a question the reader cares about; a concrete thing to *do* before any abstraction; "THEREFORE / BUT" beats so it reads like a plot; end on an open question + sandbox.
- Bret Victor "Explorable Explanations": reactive documents — scrubbable numbers inside sentences.
- Ciechanowski: one idea, one sentence, one live diagram, repeat.
- Scrollytelling (NYT Snow Fall, The Pudding): sticky graphic, each scroll step changes ONE thing.
- neal.fun: one interaction per page, near-zero text. Kurzgesagt: a recurring cute character makes huge ideas safe.

## Future Proof — real precedents (usable one-liners, sourced)
- 2018: Joshua Tauberer fixed an error in the Washington DC legal code via a GitHub pull request; the Council's codification counsel merged it — reportedly the first law change by pull request. DC publishes its official code on GitHub.
- 2012 "Bundes-Git": every German federal law in a git repo as Markdown (github.com/bundestag/gesetze — volunteer-run, not official).
- vTaiwan uses Pol.is to cluster opinions and surface statements every group agrees on; the 2015 Uber case reached seven consensus statements.
- Decidim (Barcelona, open source): used by 450+ organisations in 30+ countries (self-reported).
- Estonia's X-Road (2001): "once-only principle" — the state asks you for a piece of data once.
- New Zealand "Better Rules" / Rules as Code: legislation drafted alongside machine-readable code (OECD OPSI case).
- Catala (Inria): formalising French family-benefit law found a bug in the official OpenFisca implementation (a cap wrongly applied to overseas territories). Unit tests for law.
- Sunset clauses = TTL: in 1789 Jefferson wrote to Madison that every law and constitution should expire after 19 years ("the earth belongs to the living"). Colorado passed the first US sunset law in 1976.
- A/B testing policy: Finland's 2017–18 basic income trial — 2,000 unemployed people, €560/month; tiny employment effect, better wellbeing. "The test said: not what we expected — and that's useful."

## StoryVerse — contrast hooks
- Many-worlds usually taught as a cosmic branching tree ("pizza-you vs spaghetti-you"); Universe Splitter app.
- Wheeler's "surprise twenty questions": no word chosen in advance; the answer forms as questions are asked, each reply consistent with the previous — very close to how a story gets written. (Good interactive.)
- Rovelli (Helgoland, 2021): properties exist only in interactions — like a rainbow existing between sun, droplets and viewer. Rovelli rejects conscious-observer readings: never misquote him.
- Block universe: time as a loaf, every slice exists. Narrative identity (Dennett "centre of narrative gravity").
- Present physicists as cousins/lineage, never as support. StoryVerse is a wager.
